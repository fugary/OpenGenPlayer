# 主字幕自动翻译（macOS / iOS / iPadOS）

## 范围与入口

- macOS 15+ 与 iOS/iPadOS 18+ 使用 Apple Translation，不增加外部接口或模型依赖；tvOS 暂不支持。以下 macOS 弹窗布局保持原样，iOS 使用独立适配入口。
- 继续由“第二字幕 Beta”开关控制入口；仅选中主字幕时显示“翻译主字幕”，与已有第二字幕轨互斥。关闭主字幕同步关闭翻译并撤销旧提示，重新选择主字幕后可再次手动开启。
- 开启翻译后，选择目标语言即自动处理；目标语言按媒体独立保存；未保存的媒体首次使用上次全局选择或当前 App 语言，并固定该默认值。原文优先参考字幕轨语言，缺失时采样多条文字检测，并提供手动纠正。
- 只支持能确定对应当前主字幕且可读取文字的来源。图片字幕、硬字幕以及无法映射的字幕不猜测、不改为音频识别。
- PGS / VobSub 等图片字幕显示专门提示：需要先做 OCR，当前可切换文字字幕或加载 SRT。翻译设置和状态置于轨道滚动列表之外，避免提示被底部加载按钮截断。
- Beta 字幕弹窗统一宽度，不因首次开启翻译改变宽度。第二字幕页按“关闭/翻译入口 → 翻译设置 → 可滚动轨道列表 → 加载字幕文件”排列，分区间使用原生分隔线；轨道行高明确、按行数确定滚动区高度并裁剪边界，不再用首帧测量回填高度，防止列表覆盖设置。主字幕页仍按行数保持紧凑，长列表滚动。
- 普通第二字幕加载与翻译读取/准备/当前句等待等状态，均在第二字幕位置直接显示文字，完全复用译文的字号、颜色、阴影和位置，不增加独立底板、图标或转圈。已有译文及无字幕间隔不显示后台预翻译提示。失败和不支持同位置显示，菜单关闭和控制层隐藏后仍可见；语言选择、详细状态及重试保留在菜单。关闭翻译、关闭主字幕、切回普通第二字幕或切片后撤销翻译提示。

## 数据与生命周期

- 主字幕继续由 VLC 显示；复用第二字幕的字号、位置和时间偏移显示译文。
- Jellyfin / Emby 主字幕与翻译复用同一个服务端字幕描述和鉴权地址，以流编号关联来源；外挂字幕挂载到 VLC 后保留原菜单 ID、名称和顺序。多个字幕文件串行挂载，确认新增轨道后再处理下一个；切轨及切片后旧挂载回调不得覆盖当前选择。
- 读取完整文字时间轴，按当前播放位置优先翻译未来约 90 秒，单批限制条数与字符数；保留原始 cue 时间，异步结果按标识回填。
- 主字幕关闭、切轨、目标或原文语言改变、停止播放及关闭 Beta 时撤销旧处理，旧结果不得进入当前画面。切换片源清除翻译模式；目标语言偏好保留。
- seek 后下一批优先处理新位置；旧位置已完成的译文仅作缓存，不按返回时间直接显示。倍速按媒体时钟同步。
- 翻译缓存使用原文字串、原文语言、目标语言及缓存版本生成摘要，不持久化媒体 URL 或凭据；限量保存于应用 Caches，缺失或损坏可重新翻译。
- 首次使用由系统请求下载所需语言包，准备好后在设备端翻译。语言不支持、下载取消或翻译失败仅影响译文，提供状态和重试。
- 同语言提示“原文语言 → 目标语言：语言相同，无需翻译”；系统不支持的组合提示完整的原文和目标语言，中文明确区分简体/繁体。英语等仅地区不同且书写系统相同的组合按同语言处理；简繁转换仍按系统语言组合支持结果提示，不误标为相同语言。画面与菜单共用同一条本地化状态文案。

## 验证边界

- 纯逻辑检查覆盖时间筛选、跳转后的优先级、回填标识和缓存隔离；执行 macOS 与项目要求的 iOS 纯构建。
- 待获 GUI 授权后抽样：外挂字幕及可提取内嵌文字字幕、切主字幕/关闭主字幕/切片、seek/暂停/倍速、语言包下载或取消、语言切换/重试、Beta 关闭及原有第二字幕。
- Apple Translation 实际输出、翻译速度、原生下载呈现与 PiP 交互必须在 Mac 实机验证；构建通过不能替代这些结论。

## 首版实现

- 播放器字幕选择器的“第二字幕”页和右侧字幕检查器均提供“翻译主字幕”；目标语言来自系统支持列表，原文提供自动检测与手动选择。
- `MacSubtitleTranslation` 管理识别语言、任务代际、重试与结果；`MacSubtitleTranslationPlan` 管理提前窗口、批量限制和内容摘要缓存。
- 支持已建立来源映射的手动导入字幕、媒体服务器字幕，以及轨道数量和顺序可对应的本地容器文字字幕。自动发现的外挂字幕若无法确认与 VLC 轨道的对应关系，会提示无法读取；可通过“加载字幕文件”明确导入后再翻译。
- 主字幕切换后回到自动检测；目标语言继续持久化。翻译选择使用 macOS 独立偏好键按媒体条目保存，再次打开同一条目时等待主字幕解析后恢复；用户关闭翻译、关闭主字幕或选择普通第二字幕会清除此偏好。旧版本无此键时默认关闭，不改其他平台的第二字幕偏好格式。
- 内嵌主字幕翻译从原始容器/服务器轨道描述按顺序匹配，不使用为菜单合并后的候选列表，避免同名轨道或不同编号空间造成数量不一致。URL 明确关联的外挂字幕仍优先按来源匹配。
- 已验证时间窗口、seek 优先级、批量限制、缓存隔离、旧读取任务失效、手动语言纠正、读取失败重试与关闭中取消。未执行 App GUI / 实际 Apple Translation 会话。

## iOS / iPadOS 入口与支持范围（2026-09-13）

- 视频播放器字幕菜单打开原生“字幕翻译与音轨生成”设置页，提供翻译开关、目标语言、原文自动检测/手动选择、失败重试及版本/设备说明。首次开启翻译同时开启第二字幕 Beta；选择普通第二字幕或关闭主字幕即关闭翻译。
- 文字来源复用 iOS 现有本地/外挂/媒体服务器字幕解析与鉴权，须能够明确对应当前主字幕。生成主字幕直接逐段加入翻译会话，不因追加结果重开语言下载窗口。预翻译、缓存、状态文字与源切换隔离使用原模型；状态提示显示在第二字幕位置。
- 翻译会话附着播放器，关闭设置页不取消前台翻译；进入后台暂停处理，回前台恢复所选翻译，生成任务由用户继续。生成/翻译字幕叠层暂不进入 PiP，原字幕与 PiP 播放行为保持。
- 音轨生成为独立能力，需要 iOS/iPadOS 26+ 及支持的设备与语言，详细媒体来源和缓存语义见[音轨生成字幕](15-音轨生成字幕.zh-Hans.md)。
- 系统依据：[Apple Translation](https://developer.apple.com/documentation/translation/translating-text-within-your-app)、[SpeechTranscriber](https://developer.apple.com/documentation/speech/speechtranscriber)。Translation 运行验证需真机；纯构建和宿主逻辑检查不替代真实翻译/识别、资源下载、布局与播放同步验证。

## 相邻未完句合并翻译试验（2026-09-13，iOS/macOS）

- 保留系统 Translation 引擎、原主字幕、语言选择与翻译会话生命周期；仅改变提交给引擎的文本单元。相邻字幕无重叠、间隔不超过 0.35 秒，前句未结束且后句有小写续句或逗号续句证据时尝试合并；最多 3 条、8 秒、180 字符。明确句末、说话人标记、歌词及说明字幕独立翻译。
- 整句译文在成员字幕的原有效时段显示，不按字数拆译文，不填充原空白间隔；当前进度处于合句中段也翻译完整单元。长句/不确定边界回退原逐条处理。
- 缓存键加入合句策略版本并使用完整源文本，旧逐条缓存不覆盖新效果。生成字幕追加时重新计算单元，仅失效发生变化的译文；校验请求对应单元后接收结果，不因此重建翻译下载窗口。
- 先用纯模型检查验证边界、seek、缓存与增量失效，再纯构建 iOS/macOS。实际翻译自然度、错误合句率和可读时长需获批后用真机/Mac 片段对照，不以静态检查宣称质量提升。

## 2026-09-13 偏好与隐私播放修正

- iOS/macOS 使用既有媒体身份保存目标语言，字幕切轨、关闭翻译和重开影片保留该值；旧全局值仅作为未绑定媒体的首次默认，不覆盖已保存影片。旧翻译开关与译文缓存格式保持兼容。
- 隐私播放仍保存本地进度，设置文案明确为默认隐藏隐私播放记录；解锁后眼睛按钮控制显示，不改变存储或服务端上报语义。
- macOS 服务端上报将带原因的 `progress_*` 事件归一为进度请求，并使用播放请求携带的有效凭据；本轮不改 tvOS 播放逻辑。
