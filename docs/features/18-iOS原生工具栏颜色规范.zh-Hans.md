# iOS 原生工具栏颜色规范

## 目标与系统依据

普通导航工具按钮采用系统材质与前景适应，让深浅图片、滚动内容和系统辅助功能共同决定可读性。该能力属于 iOS 26+ 的 Liquid Glass，不限于 iPhone Duo；Duo 状态区域由系统独立管理，App 不读取其取色结果，也不承诺与状态区域逐帧同色。

- Apple [Color](https://developer.apple.com/design/human-interface-guidelines/color)：小型工具栏/标签栏可随背后内容切换明暗，默认图标与文字采用适应内容的单色外观。
- Apple [Build a SwiftUI app with the new design](https://developer.apple.com/videos/play/wwdc2025/323/)：原生工具栏提供玻璃材质和可读性处理，着色应表达明确含义。
- Apple [foregroundStyle](https://developer.apple.com/documentation/swiftui/view/foregroundstyle(_:))：自定义前景色会关闭原有材质活力效果，默认前景的层级样式保留该能力。

## 通用规则

1. 普通工具栏继续使用原生 `Button` / `Menu` / `NavigationLink`，图标继续复用 `AppToolbarIcon`。不增加自绘玻璃、背景采样、亮度阈值或颜色切换动画。
2. iOS 26+ 的普通图标默认不指定前景色，让原生工具栏决定明暗；次级图标使用系统层级前景 `.secondary`。不转成 `Color(UIColor.label)`，不在图标或其祖先上强制白/黑色；不通过全局 `UINavigationBar` / `UIBarButtonItem` tint 覆盖系统单色外观。无角标图标直接作为原生按钮 label，不再套固定 24 点的容器；带角标图标保留数量标记所需的空间。
3. 服务器根页的退出入口统一使用 `AppToolbarIcon.serverExit(...)`：iOS 26+ 与返回、首页等导航图标一样采用系统默认前景，不因轮播/滚动状态降低为 `.secondary`，避免可操作入口看似禁用。工厂仅统一图标样式，保留原生按钮位置及退出动作；通过 `legacyStyle` / `legacyForegroundColor` 保留各页面旧系统与非 iOS 分支的颜色。弹窗关闭、收起等次级动作继续使用 `secondary`；`destructive` 保留系统红色。下载数量角标等状态色保持，不把所有有色内容都改成单色。
4. iOS 15–25 保留原 `UIColor.label` / `secondaryLabel`、导航 tint 及透明页面的白色兼容。共享图标的兼容白色通过 `legacyForegroundColor` 指定，iOS 26+ 不使用它。音频页的旧版专用分支保留既有白色、20 点字号及无固定容器的布局。
5. 页面标题、品牌标志、海报与内容区不是普通工具按钮，保留独立配色。播放器自定义白色控制层不迁移此规则；音频播放页使用原生导航栏的关闭、收起、信息和播放列表入口纳入规则，旧系统保持原来的白色。macOS/tvOS 壳层不自动应用此次变更。
6. 原生搜索交给 UISearchController 管理；不接管其输入框颜色、轴方向或展开动画。保留现有按钮顺序、分组、导航和查询语义。
7. 新增普通工具按钮默认接入共享组件；确需语义颜色时说明其状态/动作含义。不得为了某一张海报再次全局锁定黑白色。

## 本轮覆盖与隔离

| 范围 | 处理 |
| --- | --- |
| Jellyfin / Emby / Plex / VOD 首页、分类与详情 | 共享图标采用原生前景；移除 Jellyfin/Emby 图标外层固定颜色；Plex/VOD 白色覆盖限定为旧系统兼容 |
| Jellyfin / Emby / Plex / VOD / IPTV / 文件型服务器根页退出 | 统一通过 `serverExit` 使用 iOS 26+ 默认前景；旧系统保留原主/次级颜色及 Plex/VOD 透明页兼容色。箭头/房子/退出的导航语义、弹窗关闭和边缘滑动退出提示不变 |
| 网络、本地/远程文件、历史、收藏、个人、设置 | 已使用 AppToolbarIcon 的普通工具项统一继承规则，不调整页面结构与操作 |
| IPTV、节目表、预览、配对、视频信息等原生导航弹窗 | 共享图标同样接入；内容区、图片和播放器控制层保持原样 |
| 音频播放页原生导航栏 | iOS 26+ 的关闭、收起、信息、播放列表统一使用共享图标，保留系统明暗处理；旧系统颜色、字号及布局不变，播放及最小化操作保持 |
| 原生返回、搜索及文字按钮 | iOS 26+ 不再设置全局导航 tint，让系统管理；旧系统保留原设置 |
| 角标、删除动作、品牌图、媒体文字 | 保留语义颜色或内容层配色 |
| macOS / tvOS / iOS 15–25 | 高版本样式仅在 `os(iOS)` 且 iOS 26+ 生效，旧颜色路径保留 |

- 已核对普通媒体库/文件/网络/历史/收藏/个人/设置、原生搜索、预览与信息弹窗的工具项。搜索兼容层的不透明导航外观仅在 iOS 26 以下启用；现代原生搜索不注入颜色或自绘材质。文件夹选择的文字导航与节目表主播放动作沿用系统文字/语义着色。
- 不额外给原生工具栏叠加 `glassEffect` 或模糊背景；工具栏自带材质负责背景适应。媒体库透明顶栏及滚动边缘策略保持，避免借此次颜色修正改变轮播位置或搜索动画。

## 验证

- 静态盘点共享图标调用、外层固定色及全局导航 tint；用最低 iOS 15 的 Simulator SDK 纯构建检查 API 兼容。
- GUI 需先按 AGENTS.md 3.8 获批：在 Duo 外屏和普通 iPhone 上，从深色轮播滚到浅色列表，检查退出/返回/Home/下载及搜索；返回首页、开关搜索和返回现场保持。
- 服务器退出图标抽样 Jellyfin/Emby、Plex、IPTV/VOD 与文件服务器：深浅背景、滚动前后均保持可辨认，点击仍返回原入口；普通 iPhone/iPad 与 Duo 遵循同一现代规则，iOS 15–25 保留原颜色，不把真正的禁用状态强制变亮。
- 抽样浅色/深色主题、降低透明度/增强对比度、禁用按钮与红色角标；旧 iOS 15/18 保留原颜色，播放器白色控制层仍可读。
- 音频播放页检查四个导航入口的材质/图标、关闭停止播放、收起进入浮窗、打开信息与播放列表；带角标/无角标及普通 iPhone/Duo 侧栏均检查原生命中区域与布局。
- 纯构建只能证明编译；图片过渡时的明暗变化、可读性与辅助功能效果必须实际验证。
