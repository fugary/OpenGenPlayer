# tvOS mpv 播放内核

2026-09-28：tvOS 接入可选 mpv 音视频播放会话；本文件描述代码覆盖范围，Apple TV 实播和 Siri Remote 验收仍待完成。

## 入口与平台边界

设置 → 高级设置 → 播放内核，可选择 VLC 或 mpv；没有已保存选择时默认 mpv，已保存的选择继续生效。使用独立的 `tvPlaybackEngine` 偏好，不改变 iOS/macOS 设置。媒体信息的「通用」分区显示实际内核；不支持的来源仍显示 VLC，不将默认设置当作实际引擎。

| 来源 | 当前路径 |
| --- | --- |
| 本地与已下载视频、HTTP(S) 视频、媒体服务器解析后的 HTTP(S) 视频 | 可选 mpv |
| HTTP(S)、RTSP、RTP、UDP 直播 | 可选 mpv；沿用直播控制限制 |
| SMB、FTP/FTPS、SFTP、NFS 原生地址 | 独立只读连接接入 mpv stream_cb；支持读取、定位与取消 |
| 音频入口 | 可选 mpv，保留原封面/遥控器界面；见 [音频对齐](24-iOS-tvOS-mpv音频对齐.zh-Hans.md) |
| Apple TV 真机 | 共用 Metal/GPU 输出，硬件/软件解码随现有设置 |
| tvOS 模拟器 | 复用有界软件渲染预览，最长边 1280、最多 4 个软件解码线程；不用于判断 HDR/性能 |

普通点播播放中可从原「播放调整」面板选择内核。切换会重新加载当前片源，恢复进度、暂停意图、画面比例、填充模式和可核对的轨道，不是无缝切换。选择只作用于当前影片；片尾重播保留该选择、画面设置和可核对的轨道，从零开始播放，下一集遵循默认内核。准备期间禁用切换；无时长/不可 seek/直播不做普通切换；明确失败后仍可在该面板切回 VLC。失败时播放键重试当前内核，原返回关闭保持可用。

## 已接入链路

- 沿用原播放器与 Siri Remote 控制层：播放/暂停、快进快退、拖动后确认 seek、速度、硬软解、音轨和主字幕、画面比例/填充、上一项/下一项/自动续播与播放列表。seek 预览保留服务器图片优先；mpv 使用独立静音解码会话，PQ/HLG 在 CPU 映射至 SDR，未知色彩或失败保留时间反馈，不切 VLC。
- 视频画面挂载在原容器中；浮层、遥控器返回顺序、焦点范围和默认焦点沿用既有实现，不增加另一套控制层。新的内核选择按钮使用原面板焦点样式；实际焦点流转需设备检查。
- MPV 输出时钟用于本地历史及媒体服务器进度回报。MPV 轨道编号不写入 VLC 历史字段，音轨/主/第二字幕使用独立的逐影片语义偏好；相同影片重建用容器序号与数量或外挂源地址核对，不按数值 ID 跨内核套用。切回 VLC 先识别原生外挂与合成菜单项，再核对内嵌轨道数量；手动改选会撤销尚未完成的恢复。无法对应时不猜选其他语言。
- 内核提供的文字第二字幕交给原应用字幕层显示，沿用位置调整、空白时段命中和字幕延迟；主次交换先释放冲突槽，同轨镜像主轨已解码文字。图片第二轨已使用 mpv 原生合成（见下方 2026-09-30 更新），未知格式仍受可读性限制。文字路径只消费当前解码文字，不提供全文浏览或翻译/生成，也不能镜像尚未解码的未来对白。
- 主字幕沿用内置 CJK 字体并按 VLC 相对字号及字体度量换算；ASS 自带排版保留。本地/HTTP(S) 外挂及 SMB/FTP/FTPS/SFTP/NFS 外挂候选均接入 mpv。NAS 首选和其他候选通过独立连接逐条读取，单文件上限 8 MiB、每次最多 1 MiB；空文件、超限或读取失败不阻塞其他字幕与播放。临时文件由当前引擎接管并在释放时清理，来源映射回原地址以恢复主/第二字幕；切片、退出或失败取消旧读取。远程外挂认证、特殊编码、缺失服务端轨道仍需专项验证，未宣称全格式对齐。
- 音频/字幕延迟在 mpv 上直接修改属性；切解码器与内核重建保留暂停意图，VLC 使用 `start-paused`。播放请求、内核回调、下一集、延迟刷新和外挂加载核对原会话；切换回 VLC 时换用新播放器对象，避免旧对象通知操作新影片。

## 验证和剩余工作

### 2026-10-03 字幕候选与播放弹层

- 本地视频准备时把同目录所有字幕与请求中的外挂候选合并、去重并保留在当前媒体中；首选字幕只决定初始选择，不限制主/第二字幕菜单候选。NAS 继续使用独立、有界、可取消的读取。
- Jellyfin/Emby 未提供 `DeliveryUrl` 时，字幕回退地址使用 `Stream.<格式>`，保留 ASS/SSA 等原格式，SubRip 使用 SRT；有服务端地址时继续优先使用该地址。
- 全屏 UIKit 宿主收到 Menu/Back 后交给当前播放层处理，不直接关闭全屏呈现。选项子页先回分类，分类先关面板；播放列表、位置调整、原生菜单各先关闭自身，视频控制层再隐藏，最后退出播放。子菜单状态归属播放会话，根播放层统一处理；播放器窗口识别 Menu/Back 并消费，离开时移除识别器，取消不触发退出。播放期间禁止被覆盖媒体库退栈，退出通知使用独立事件流，不驱动呈现根视图刷新。
- 原生快速菜单通过 UIButton/UIMenu 的实际生命周期维护展示状态，关闭时恢复轨道刷新和控制层计时，不再按固定 12 秒误判菜单关闭；标签前景交给原生菜单处理。选项面板标题与分类分行，分类标签居中，内容高度有界并按实际测量调整；音轨和主/第二字幕使用独立焦点标识，当前选择保留勾选。播放内核在一级行显示当前值，进入二级后选择 mpv/VLC，勾选对应当前内核。所有选项子页进入时统一聚焦“返回”，一级页面聚焦当前分类。

Jellyfin/Emby 候选限当前媒体版本；首选字幕准备失败不跳过挂载。mpv 加载后按服务器元数据补挂可导出字幕，以来源身份去重、核对内嵌轨映射，不跨内核套用数字编号。

用户日志捕获旧播放器全屏呈现在原生菜单仍打开时被撤销。播放器现改为同场景独立 UIWindow 的根控制器，覆盖已有服务器全屏页；播放请求结束或宿主拆除时移除窗口并归还原 key window，移除原 modal delegate/dismiss 保护。Debug 的 `[TVPlaybackExit]` 日志继续区分返回来源、分层动作、窗口移除和播放请求清理，新窗口版本仍待实测。

上述改动已做 tvOS Simulator SDK 纯构建及无界面模型检查；字幕真实加载、长列表焦点、菜单取消/停留和 Siri Remote 逐层返回仍待按 3.8 获批验收。

播放选项面板的顶部仅随视口变化，不随 Tab/子页内容高度变化。标题与分类栏居中固定，内容高度实际测量并按剩余视口限制，长列表在内容区滚动；少量条目仅收缩底边，减少动态效果开启时取消高度动画。一级不重复分类标题，行样式减少底框与描边，短值右对齐、长轨道名放第二行；保留主/第二字幕和内核等二级选择、原生按钮交互及现有焦点/返回规则。信息组织参考 [Apple TV 音轨与字幕选项](https://support.apple.com/en-ie/118411) 与 [Infuse 分类菜单说明](https://support.firecore.com/hc/en-us/articles/215090907-Subtitles-and-Audio-Tracks)，并非其界面复刻。

切分类和子页保留滚动容器，通过滚动定位恢复页首；子页“返回”挂载后设置默认焦点并显式请求聚焦，切页或关闭时撤销旧焦点请求，避免旧页面回调把焦点拉回 Tab。当前轨道和内核的勾选不承担子页默认焦点。

子页内点击顶部 Tab 会清除旧子页并进入目标分类首页，点击当前 Tab 同样回该分类首页；子页内仅移动焦点到 Tab 不自动离开子页。媒体库、文件服务、IPTV 及历史/收藏统一从主界面显示独立的全屏浏览 NavigationStack，移除服务器 fullScreenCover 和无效的交互关闭保护。主页面保留现场但隐藏并禁用交互。浏览容器从自身捕获导航控制器，通过环境传递给页面；返回与首页不再查找全局 key window，子页只退当前浏览栈，根页才清除浏览会话。导航栈未挂载、退栈动画中或同一次事件重复分发时不得误退出；隐私解锁页有显式返回。实际 tvOS Back 行为仍待设备验证，Debug `[TVNavigationExit]` 记录无敏感信息的返回分支与栈深度。

纯构建和模型检查结果见当月开发日志。未运行 App、模拟器或操作遥控器；构建不证明播放、网络、显示效果、焦点、HDR 或性能通过。

tvOS 原生 NAS 流桥及 iOS/tvOS mpv 音频已接入，设备验收仍待完成。2026-09-30 接入 iOS/tvOS 原生第二图片字幕：使用 mpv 第二槽直接合成到视频，核对选轨结果、处理同一图片轨冲突并在关闭时清除输出；沿用第二字幕延迟，tvOS 遥控位置调整控制原生位置百分比。图片不进入文字叠层，也不显示假文字调整框；上半屏/整屏图形可能保持原位，菜单明确说明。详见 `docs/tasks/双内核架构完善.zh-Hans.md`，真实位图、同步和遥控操作未验收。

iOS SDR 已接入独立 mpv 连续 CVPixelBuffer 输出、应用文字/生成/翻译字幕合成与公开 AVKit PiP，通过渲染 API 输出而非逐帧截图轮询；PQ/HLG 已接入同一帧输出及字幕合成，HDR 映射至 SDR；未知色彩失败恢复原播放，设备验收仍待完成。PiP 控制器仅接入 iOS；tvOS 只复用独立像素输出生成预览，不扩展 tvOS PiP。

tvOS mpv 的名称/序号恢复采用名称优先、序号兜底，保留服务器外挂展示名参与匹配。进入 mpv 时重新读取语义偏好，不因 VLC 旧数字 ID 存在而丢弃查询；本次显式名称/序号优先于该影片的旧 mpv 记录，同片跨内核恢复仍最高优先。待恢复名称/序号存在时，自动发现的首个外挂不抢先覆盖选择；手动选择继续撤销旧恢复。显式字幕序号不会被继承的关闭偏好抑制。上述路径及遥控器操作仍待设备验收，不将数字 ID 跨内核持久化。

最小获批设备回归（按 AGENTS.md 3.8；不默认截图/录屏）：

1. Apple TV 打开本地/HTTP MKV，检查实际内核、播放/暂停、拖动确认 seek、速度、比例、填充、硬软解；暂停中切 VLC↔mpv，时间与暂停不变。
2. 音轨 A/B，主/第二字幕 A/B、互换、同轨、关闭、延迟及空白位置调整；多条 NAS 外挂均可选择，带外挂时 mpv→VLC 仍恢复原内嵌字幕；外挂后到不抢回手动选择，重新打开仍保留独立偏好；不支持的第二轨不可选。
3. 默认 mpv 时手动切 VLC，片尾重播仍使用 VLC、保留画面与轨道且从零播放；选片、自动下一集、关闭重开及失败后切 mpv，旧播放不复活、不残留声音/字幕；历史、服务端进度和播放列表当前项正确。
4. 遥控器进入/退出选项和播放列表，焦点留在浮层，Menu/Back 逐层关闭；抽查原 VLC 音频与 NAS。真机另验 4K/HDR、长时间内存和功耗，模拟器只验证功能。

## 2026-09-30 独立 mpv 目标预览

- SDR mpv 预览使用独立静音解码器与只读 NAS 流，复用主播放的 WebDAV 凭据及 VOD/115 请求头；不改变主会话时间、字幕、音频与暂停状态。输出长边最多 540 像素，缓冲池最多五帧，iOS/PiP 默认 480 像素不变。
- 取消、切片及关闭丢弃旧图；失败或 6 秒超时退回时间文字，取消不触发回退。服务器预览与缓存仍优先，PQ/HLG 在 CPU 映射至 SDR，mpv 预览不再启动 VLC。
- tvOS 与 iOS 纯构建、52 项真实缓冲区/交付/合成检查、26 项预览/元数据接口检查、16 项实际 mpv 预览生命周期/图像转换检查通过。后者替换原生解码器，不打开媒体；实际遥控预览、时间准确性、色彩、NAS 认证和资源占用待批准设备验收。

### HDR 预览更新（2026-10-01）

mpv 的 PQ/HLG 预览使用独立静音会话与 CPU 高精度色调映射，输出 SDR 小画面；失败、超时或未知色彩退回时间文字，不再调用 VLC 预览器。普通 HDR 播放保持原路径。合成色阶与纯构建不代替电视上的色彩、遥控器拖动及 NAS 验收。
