# 模块 01：本地文件管理（导入/管理/预览）

## 1. 当前功能概览

- 本地文件浏览支持网格/列表两种视图，并支持搜索、排序、下拉刷新。
- 排序菜单采用单层分组结构，直接在一个菜单内展示 `Sort By` 与 `Sort Order`，与 Jellyfin 库页保持一致。
- 支持文件 App 导入、相册导入（在列表页入口）、新建文件夹、重命名、删除、移动等常用管理动作。
- 支持调用系统分享面板导出本地文件；外部 App / 系统“打开方式”传入的文件会自动导入 `Documents` 根目录，并切回文件页展示。
- 支持基础预览（图片/文本）与媒体播放入口（视频全屏、音频播放器）。
- 新增常用文档预览能力：`PDF / DOC / DOCX / PPT / PPTX / XLS / XLSX / Pages / Numbers / Key` 在本地文件页内可直接走系统 `QuickLook` 预览。
- 对暂不支持应用内预览的本地文件类型（如压缩包、设计源文件、未知二进制等），预览页会提供明确的“在其他 App 中打开”按钮，不再只停留在静态“不支持”提示。
- 文本预览扩展名统一由模型层维护，`json / xml / md / log / csv / yaml / plist / strings / nfo / cue / lrc` 等纯文本文件在本地、远程、收藏和个人页入口保持一致的预览语义。

## 2. 关键实现位置

- 页面入口：`MainTabView` → `FilesListView`。
- 文件管理服务：`FileManagerService`（本地目录读取、刷新、文件操作）。
- 预览与播放分流：`ImagePreviewView` / `TextPreviewView` / `PlayerView` / `AudioPlayerView`。
- 公共设置：`AppSettings`（本地列表布局与排序偏好）。

### macOS 本地目录授权

- 本地首页通过系统目录选择器添加授权目录，子目录只提供“新建文件夹”。重复选择已有目录时必须使用本次选择携带的权限创建新安全作用域书签，替换旧书签、释放旧访问缓存并重新激活，不能仅返回原记录。
- 同一目录的真实路径与 App 沙盒内符号链接路径按规范化后的实际路径匹配；已有同目录记录一并更新授权，保留各记录的 id、名称、路径与其他元信息。默认目录初始化同样识别等价路径，避免重新新增；同名但实际路径不同的目录不能误匹配。
- 新书签创建失败时保留已有书签及访问状态，不新增无效授权记录；显式重新授权采用同一更新规则。列表中的警告继续依据真实目录访问检查显示，不能只因用户点过“选择文件夹”而强制隐藏。
- macOS 首页条目显式携带授权记录 ID，列表身份、重命名、移除授权和访问检查均使用该 ID。真实路径与链接记录可以解析为同一 URL，但不能共用列表身份或误操作另一条记录；首页重命名只修改显示名，记录失效时不得回落为磁盘重命名。子目录仍按文件 URL 浏览，授权查找同时识别存储路径、解析路径及等价链接。
- 多个授权记录覆盖同一路径时优先精确匹配，否则选择相对目录层级最近的授权记录，同层级保持保存顺序。默认父目录的沙盒链接不能抢先覆盖已单独授权的子目录，匹配优先级不按链接路径字符串的长度决定。

## 3. 开发实现步骤（建议模板）

1. **定义交互**：先确定本次变更发生在列表/网格/菜单哪一层。
2. **补服务能力**：优先在 `FileManagerService` 扩展文件操作与状态刷新，避免在 View 中堆业务逻辑。
3. **接入页面状态**：在 `FilesListView` 绑定状态（搜索、选择、批量操作、弹窗）。
4. **联动播放与预览**：根据文件类型跳转到对应预览或播放器。
5. **持久化用户偏好**：必要时在 `AppSettings` 中落地开关/排序等配置。
6. **回归检查**：覆盖导入、重命名、移动、删除、播放、刷新等主路径。

## 4. 后续迭代建议

- 为大目录场景补充分页/增量加载策略。
- 统一本地与远程文件列表交互（减少不同页面心智差异）。
- 增加文件冲突处理策略说明（重名覆盖/重命名规则文档化）。

## 5. 近期实现补充（2026-03）

- 文件网格/列表卡片支持真实缩略图预览：视频与图片优先显示画面，音频优先显示封面；加载失败自动回退默认文件图标。
- 文件缩略图新增右下角圆形类型徽标（视频/音频/图片/文档等），在启用预览图后仍可快速识别文件类型。
- 文件列表新增媒体时长展示（有时长时显示 `mm:ss` / `hh:mm:ss`），并与原有日期、大小信息共存。
- 音频/视频条目在有历史播放记录时可显示圆环进度，视觉上与音频 mini 模式“进度环”风格保持一致。
- 文件型条目图标新增按扩展名细分：`PDF`、`Word/Pages`、`Excel/Numbers/CSV`、`PowerPoint/Keynote`、压缩包、设计源文件、字体文件不再共用同一个 `doc` 图标，列表、网格、拖拽预览与“在其他 App 中打开”动作页会保持一致的图标与颜色语义。
