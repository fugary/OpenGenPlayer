# GenPlayer 功能实现文档索引（持续维护）

## 文档使用方式

- 面向对象：产品/开发/测试都可直接查看。

- 建议规则：
  - **先更新设计，再改代码，再回填结果**。
  - 每个功能都记录“入口页面 + 服务层 + 数据存储 + 回归清单”。

## 当前建议补强方向

- 建立统一“功能状态看板”：规划中 / 开发中 / 已上线 / 需要重构。
- 下载中心能力可基于现有 `DownloadCenterService` 与设计文档继续推进。
- 增加模块级回归清单（建议后续沉淀到测试文档）。

## 最近更新（持续维护）

- 模块 12 新增“IPTV 与电视直播”专项设计，明确以 M3U/M3U8 解析为基础，结合 VLCKit 强大的流媒体播放能力，为 iOS/iPadOS/tvOS/macOS 提供纯净、合规的电视频道聚合与直播体验。
- 模块 11 新增“内嵌第二字幕”专项设计，明确第二字幕以内嵌文字字幕轨为主，优先通过 Jellyfin / Emby subtitle stream 导出与后续本地抽取实现，不把外挂字幕作为主路径。
- 模块 08 新增“远程媒体质量与转码选择”专项设计，明确默认仍以原始文件直连/直出为先，质量选择复用现有播放前选项面板承载，并与下载中心离线语义严格分离。
- 模块 10 新增“多端适配”专项设计，明确本轮先建立跨平台入口、macOS/tvOS 壳层与播放器抽象接口，不直接把 iOS 视图树整包迁移到新 target。
- 模块 07 新增“文档预览与外部打开”专项设计，定义 `QuickLook + 系统分享面板` 为基线方案，并收口本地/远程/收藏/个人页的统一文件预览路由。
- 模块 02 补充了 Jellyfin/Emby 详情跳转链路统一方案（先库页再详情）与剧集解析策略（Episode/Season 先回到 Series）。
- 模块 02 新增媒体库封面点击命中稳定性修复，以及 Jellyfin/Emby 库页 Grid/List 展示模式与持久化策略说明。
- 模块 02 新增 Jellyfin/Emby 列表模式信息密度优化与排序菜单重构（字段与升降序分组、状态标识更清晰）。
- 模块 03 新增自动连播跳集修复与“剧集级字幕/音轨偏好记忆”规则说明。
- 模块 04 补充了历史/收藏的导航一致化、破坏性菜单语义、服务器顺序实时刷新和历史缩略图稳定性说明。
- 模块 04 补充了历史剧集封面的 `Series Primary` 回退策略，以及对应回归检查规则。
- 模块 05 新增测试/生产双 bundleID 并行安装策略，以及国内/海外默认商业化模式设计建议。
- 模块 06 新增静态官网、隐私政策页、反馈页与 GitHub Pages 发布方案设计。
