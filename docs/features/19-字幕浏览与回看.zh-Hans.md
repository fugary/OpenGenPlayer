# 字幕浏览与回看（第一版）

## 范围

iOS/iPadOS 视频播放器字幕菜单提供“字幕浏览”，使用原生可展开面板；macOS 视频播放器字幕选择器提供相同入口，在独立右侧栏浏览，展开/收起复用播放列表的右侧滑入/滑出过渡与 0.18 秒 easeInOut 动画。tvOS 与音频播放器不增加入口。

- 按时间列出当前主字幕或第二字幕的文字，可在两个位置之间选择浏览；选择浏览位置不改变播放字幕轨或字幕生成/翻译设置。
- macOS 浏览面板内直接提供当前槽位的原生字幕轨选择菜单（含关闭），与原字幕菜单共用切换逻辑；只有显式选择轨道才改变播放设置。换第二字幕后仍留在第二字幕浏览，不因来源标识改变跳回主字幕。
- 高亮当前字幕，默认跟随播放；手动滚动或搜索停止跟随。“定位正在播放的字幕”清除搜索并滚回当前句，无对白时定位邻近句，不跳转视频；它不是撤销字幕点击跳转，第一版不保存跳转前进度。
- 关键词搜索忽略大小写与重音，显示匹配全文、时间及高亮关键词；只搜索当前来源已读取的文字。
- 点击整行按字幕实际显示时间跳转，沿用播放器暂停/播放状态与已有 seek 路径，不自动循环、自动暂停或修改倍速。
- 文字字幕复用现有外挂、可提取内嵌及远程字幕读取。图片字幕、无可读来源、读取失败分别提示，可重试失败。
- 已生成/已翻译字幕只读取当前有效结果，不因打开浏览器启动生成或翻译；未完成时明确标为“仅含已生成/翻译的字幕”，不能把不连续已完成区间当成全文。

## 数据与隔离

共享浏览模型只处理文字、时间、过滤及跟随定位；两端适配器各自提供当前字幕来源和时间偏移。时间偏移遵循该端现有显示路径，不顺带修改原有字幕延迟语义。生成结果追加时保留稳定行标识、搜索与手动浏览状态。

读取仅在面板可见时发起。媒体会话、字幕来源、加载请求分别识别；关闭、切片或换字幕后撤销旧读取结果，禁止旧任务回填。文字和带凭据地址不写诊断日志，不新增远程写入或持久化。

macOS 文件型服务器的 MKV 内嵌文字字幕独立按范围读取：核对容器字幕轨顺序与 VLC 原始内嵌字幕数量，再读目标轨，不能猜选其他轨道。优先读取 Matroska Cues 指向的字幕块，明确标为“索引中可读取的字幕”（索引可能不完整）；无字幕索引时有界扫描元素头并跳过音视频负载。读取有 64 MiB / 16,384 次请求上限（底层协议可能有更严格限制），超限提示下载到本地再浏览，不自动下载整部影片。图片、压缩或加密字幕不进入文字解析。两端原播放器/音轨生成路径不扩展。

macOS 本地片源的主字幕映射使用原影片独立预解析得到的字幕 ID 与顺序；播放菜单中自动发现或后来挂载的字幕不计入容器轨道数。独立解析只读本地元数据、不创建播放器；切换/关闭时取消。只将确认为原影片轨道的 ID 映射到提取器，不能把多出来的字幕项按顺序猜成内嵌字幕。

macOS 浏览视图随播放进度刷新时仅解析内存中的来源映射，不同步读取本地影片。容器轨道描述在浏览加载任务中后台读取，已加载全文由当前影片会话和字幕来源标识复用；进度与字幕延迟变化不触发重新读取。普通字幕选择与翻译的原解析路径保持独立。

格式依据：[Matroska 元素规范](https://www.matroska.org/technical/elements.html)、[字幕索引建议](https://www.matroska.org/technical/cues.html)。

## 验证

纯逻辑检查覆盖搜索、清理标记、时间边界/重叠/空白区、正负偏移、生成增量行标识和过期读取隔离，以及本地播放菜单含额外字幕时的原影片映射（问题片源只读提取 145 条，无播放器/GUI）、MKV 索引/无索引、多字幕轨匹配、时间尺度、ASS/UTF8、跳过视频负载、读取预算、损坏数据、取消和短读；完成 iOS Simulator SDK 与 macOS 纯构建、八语言资源一致性检查。

GUI 检查须按 AGENTS.md 3.8 获批后执行：本地 SRT/ASS 及可读内嵌字幕浏览与暂停 seek；主/第二字幕切换与延迟、macOS 浏览面板内换轨及关闭；NAS MKV 多轨文字及实际读取速度；远程读取中切片/关闭；生成/翻译追加时搜索与滚动不跳回；iPhone/iPad 横竖屏、macOS 窄窗口及字幕导入/失败弹窗/PiP 原行为。未经实际操作不得视为通过。
