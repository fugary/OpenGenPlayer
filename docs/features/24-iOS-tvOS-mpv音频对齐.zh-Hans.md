# iOS / tvOS mpv 音频对齐

2026-09-28：音频入口接入可选 mpv。下表是代码接入与回归范围，不能代替设备实播验收；mpv 现为默认内核，但这不表示整套视频功能已完全对齐。

## 入口

高级设置中的「播放内核」移到音视频共用分区。iOS 和 tvOS 各自保存设置；新打开的音频与视频采用该默认值。不支持的媒体类型/协议继续 VLC。媒体信息的「通用」显示实际内核。

iOS 音频仍使用原 sheet、封面页与悬浮播放器，新增原生更多菜单提供内核、音轨和延迟；tvOS 沿用原封面、遥控器、选项与播放列表。在可 seek 且有时长的点播中切内核会重新加载，保留位置、暂停和可核对的音轨，只作用于当前条目；iOS 的原生失败 Alert 可直接改用 VLC，tvOS 的原播放调整面板保留失败切换。音频不增加视频画面、字幕智能、浏览或 PiP 入口。

## 与既有 VLC 音频链路的核对

| 链路 | iOS / iPadOS | tvOS |
| --- | --- | --- |
| 音频启动 | 显式 `audioOnly` + `startAudio`，不依赖视频视图 | 同左，并串行激活音频会话 |
| 来源 | 本地/离线、HTTP(S)、原媒体服务器解析入口、SMB/FTP/FTPS/SFTP/NFS、网络流 | 同样接入独立 NAS 只读连接；共享视频路由也可使用 |
| 音频输出 | `vid=no`、`vo=null`，不创建 GPU/软件视频渲染；不解码封面成视频 | 同左 |
| 暂停 / seek / 倍速 / 延迟 / 音轨 | 现有服务入口转发到 mpv；默认倍速读取音频设置 | 原遥控器/进度控制转发，音频可调整延迟 |
| 播放列表 / 结束 | 自动下一曲、顺序/随机/单曲重复，重复从 0 开始；异步解析采用最新切曲请求 | 原上一项/下一项/自动继续，末曲结束保留当前内核与可核对的音轨，从零重播 |
| 续播 / 历史 / 服务端进度 | 音频历史开关、媒体类型与 mpv 时钟；不用视频历史开关代替 | 沿用 HistoryService 的音频开关及服务器进度 |
| 轨道与切内核 | 当前音轨按容器数量和序号核对；mpv 偏好独立，编号不写入 VLC 历史 | 同左 |
| 封面与元数据 | 保留原缓存/服务端封面、VLC 元数据解析及本地 AVFoundation 提取；mpv 标签更新曲名/歌手/专辑 | 保留原封面加载与元数据后备，mpv 标签补充 |
| 浮窗 / 后台 | 原浮窗生命周期及后台开关；禁止后台播放时暂停、回前台不自动重启 | 维持电视原播放页生命周期，离开关闭清理 |
| 系统控制 | 原锁屏/控制中心信息、播放/暂停、上下曲、进度及封面；中断和输出设备断开暂停 | 新增 mpv 音频系统信息与控制；只注册并清理自己的命令处理器 |
| 中断 / 恢复 | 系统中断撤销已激活缓存；仅系统允许恢复且用户控制/播放尝试没变化时恢复 | 中断与输出设备断开暂停，显式继续时重新激活；旧激活结果不能覆盖新控制 |
| 错误 / 重试 / 退出 | 原加载策略和原生 Alert，重试/切 VLC/关闭撤销旧准备 | 原错误提示/重试/返回；重试或切 VLC 清理旧播放与系统信息 |

VLC 在 mpv 音频模式中可继续提供独立的元数据解析，不启动另一个 VLC 播放器；“实际内核 mpv”指音频解码与输出。远程封面仍受原来源能力、认证和后备读取限制，不保证所有文件都带有可读封面。

NAS 连接不借用文件浏览或下载连接，分块读取并支持取消。tvOS 扩展的是既有范围读取模块的编译与播放接入，不新增整片下载步骤；原电视元数据后备下载策略保持不变。

## 验证与验收

最终 SDK 构建、模型、音频会话单元检查、回环传输、本地化和静态依赖检查结果记录在当月开发日志。音频会话单元检查使用模拟后端，不会输出声音或操作 App。

尚需按 AGENTS.md 3.8 获批后执行以下四组（不默认截图/录屏）：

1. iPhone/iPad 本地 MP3/M4A/FLAC/WAV，检查冷启动、元数据/封面、暂停拖动、倍速、单曲重复、随机/顺序及末曲停止；与 VLC 使用同一文件对照。
2. iOS 浮窗收起/展开、锁屏控制、耳机断开/中断、后台开关与准备中切后台；当前会话不误自动恢复、不多路出声；关闭清理控制中心。
3. iOS 和 Apple TV 各抽样 HTTP/媒体服务器、SMB 与另一种 NAS 协议，播放、seek、失败重试和 mpv↔VLC，核对暂停、音轨和进度；快速连续切曲后只播最后一次选择。
4. Apple TV 封面页、遥控器上下曲/进度与内核面板焦点、系统播放控制、末曲重播及退出（默认 mpv，手动切 VLC 后重播仍使用 VLC）；再抽查 VLC 视频与音频、iOS 视频/PiP 和 macOS 音频。

未解决的全播放器差异仍包括 iOS 原生 mpv PiP、第二图片字幕及真实 HDR/功耗/长播对照；它们不是本次音频接入已验收的项目。
