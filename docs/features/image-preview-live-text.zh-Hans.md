# 图片预览实况文本

- iOS/iPadOS 和 macOS 图片预览复用播放器的 `PlayerLiveTextViewer`，识别已加载的当前原图，提供系统文字选择与复制。
- 仅在 `LiveTextCapability.isSupported` 且图片准备完成时允许进入；旧系统和不支持设备保留普通预览，tvOS 不扩展。
- 选字界面独立呈现，关闭后恢复原预览；保留 iOS 缩放、翻页、工具栏显隐及 macOS Quick Look、前后切图、默认应用入口。
- 远程图片沿用现有下载/缓存路径，不为识别再次下载；切图、关闭时不得将旧图加载结果用于新图。
- 验证范围：双端纯构建；GUI 待批准后抽样本地/远程图片选字复制、关闭恢复、切图与缩放，以及不支持设备入口隐藏。
