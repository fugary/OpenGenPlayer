# GenPlayer 核心手工回归清单

### tvOS 字幕候选与播放弹层（2026-10-03）

- 读取速度会话隔离：远程 mpv 正在显示非零读速时切换 VLC、切换影片或退出重开，旧读速必须立即清空；新影片准备失败也不能保留旧统计。再切回 mpv 后只显示当前会话读速，原进度、暂停和字幕选择保持。按 3.8 获批后执行。

- tvOS 第二字幕：同轨和不同轨道默认统一位于下方 84%（主字幕区域上方），主字幕保持原位置；ASS 整层平移并保留字体、颜色、相对布局及特效。显式位置优先，重置回下方 84%。抽样同轨、不同轨、关闭主字幕、切片和暂停中改位置，核对字体/颜色/特效、独立延迟与菜单勾选一致。模拟器 1080p 视口核对字幕清晰度，真机单独验收；普通文字、位图和原生 ASS 均核对下方默认位置与调整/重置语义。

- 面板样式：连续切换四个分类及二级选项，标题和 Tab 的顶部位置保持一致，只有底边随内容变化；少量条目紧凑、长列表内部滚动，焦点放大不裁切。音视频分别抽样 720p/1080p 视口、德语等长标签和“减少动态效果”；分类切换不继承上一个长列表的滚动位置，短值右对齐、长轨道名第二行仍可辨认。操作前按 3.8 获批。
- 独立播放窗口回归：从服务器全屏页、历史、收藏分别播放并退出，确认回原页面且焦点可用；快速关闭重开、换片、音频/视频与应用前后台无黑窗、旧声音、迟到重开。菜单返回不应出现 `playback-window-close` 或播放器 `onDisappear`，仅真正退出时关闭窗口。窗口替身检查不代替此项设备验收。
- 按 3.8 获批后，对比同一 Jellyfin/Emby 媒体版本的内嵌与外挂主/第二字幕菜单；覆盖服务端提供 DeliveryUrl 和按编码构造 Stream 地址两条路径。抽样 ASS/SSA/SRT、本地同目录多字幕及 NAS；读取失败不阻断其他字幕或播放，切片/退出取消旧读取。
- 分别打开原生音轨/字幕/倍速/画面菜单，停留超过 12 秒后按返回或选项确认；关闭后仍在播放器，控制层和轨道列表可再次使用。更多 → 分类 → 子页逐次按返回，应依次回分类、关面板、隐藏视频控制层、退出播放；播放列表和字幕位置调整先关闭自身，暂停与音频链路保持。
- 返回入口分别抽样新版模拟器底部「‹」和遥控器 Menu/Back；播放器打开期间，底层媒体库不得退栈或销毁呈现宿主，真正退出后返回仍能正常导航。更多 → 播放调节 → 播放内核：一级显示当前值，二级 mpv/VLC 勾选当前项；返回只退一级，切核保留原进度和暂停状态。
- 选项面板一级打开后聚焦当前分类，进入音轨、主/第二字幕、内核、画面及信息等子页后统一聚焦“返回”，向下可达选项，当前值仍保留勾选；快速进入/返回/切分类或关闭重开，不被旧请求拉回 Tab，焦点不落到背景。抽样长字幕列表首尾、上下跨分类及字幕加载后追加。面板标题/分类不重叠，少量条目无大块留白，长标题及八语言分类不溢出。上述交互与视觉不能用纯构建代替。
- 子页向上移动焦点到 Tab 后按确认：其他 Tab 切换至其分类首页，当前 Tab 回到当前分类首页，旧子页不残留；焦点移动与确认均可达，随后重新进入子页仍先聚焦“返回”。
- 服务器逐级返回：Jellyfin/Emby/Plex 的分类 → 详情、文件服务连续两层文件夹，以及历史/收藏打开的服务器页面，逐次按遥控器 Back 和模拟器「‹」，每次只退一级，根页才退出；首页按钮仍回服务器根页。抽样播放退出后继续返回、原生菜单/搜索/隐私解锁取消，确认背景主 Tab 不可聚焦、关闭浏览后原焦点和页面仍可用。Debug `[TVNavigationExit]` 应区分 `custom-page-back`、`pop-browsing-page` 与根页 `exit-browsing-root`；同一次按键及退栈动画中的重复回调不能关闭根页，未挂载导航栈时不误退出。不以纯构建或替身模型检查判定设备交互通过。

### iOS/macOS mpv 原生 ASS 第二字幕

- 历史字幕 URL 补充对照：带连字符/紧凑 UUID、DeliveryUrl 的 `/0/Stream.ass` 与构造 `/Stream.ass`、`ApiKey/api_key` 变化应映射同一轨道；不同版本/轨道、非零起点及内容选择查询不得误合并。

- iOS 从历史与详情打开同一 Jellyfin/Emby 媒体版本，覆盖先加载旧下载地址、后返回 PlaybackInfo：稳定后主/第二字幕数量相同，同轨名称一致，真正外挂仍可用；副本选中时清理后主/第二字幕仍播放原轨道。抽样 token 变化、不同版本、转码无内嵌轨及切片，确认不误删其他轨道或中断字幕；按 3.8 获批后操作。

- iOS 第二字幕菜单：ASS 不再显示重复的“第二字幕大小/位置”子菜单，仍可点击字幕后拖动，空白时段保留命中区域；位图字幕仍有位置菜单，原有大小设置入口保留。抽样新版原生菜单及 iOS 15 备用菜单、横竖屏与锁定状态；操作前按 3.8 获批。

- 操作 App/模拟器前按 3.8 获批。使用已知字体附件、卡拉 OK、动画和画面贴字的本地 MKV/ASS 外挂，开启第二字幕 Beta，主轨 A、第二轨 B，核对原样式、字体和特效；再抽样 HTTP/NAS 外挂认证，读取失败不影响播放。
- macOS 悬停、iOS 点击后，调整框恢复整行宽度，高度与纵向位置贴合原生内容，有对白时不显示占位标签；空白时段保留可拖动区域。播放和暂停下调整大小/位置，检查主轨不变、整套动画/定位元素随第二轨变化及位置记忆；iOS 横竖屏、黑边和窗口变化后仍对齐，锁定/菜单期间不误触播放手势。普通文字/翻译/生成字号保持。
- iOS Jellyfin/Emby 外挂主/第二字幕菜单显示服务端名称；元数据缺失时使用简洁文件名或字幕编号，不出现请求地址或认证参数。
- 同轨 ASS 镜像须保持字体、颜色、定位与动画，不回退纯文字；主/第二延迟不同及任一位置空白时段不能残留旧画面。iOS Jellyfin/Emby 核对内嵌字幕的服务端下载副本不会重复挂载，真正外挂仍可选，转码无内嵌轨时保留下载回退，旧副本选择恢复到原内嵌轨。
- 主次 A/B 互换、同轨镜像、主轨关闭或替换为生成字幕、关闭第二轨/Beta、切片/切内核，核对状态和无旧字幕残留；主/第二延迟、暂停 seek、字幕浏览全文/部分标记和搜索回看保持原时间语义，取消读取不回填。
- macOS 播放与暂停状态下各做 mpv → VLC → mpv，确认 VLC 画面/声音恢复、进度和暂停状态不变；对比有/无第二字幕、内嵌/外挂及非零延迟，核对选中轨、位置/大小偏好与浏览回看。再抽查退出后重开及切集，旧视图回调不启动旧影片；iOS 核对新 VLC 内嵌轨不会被旧 mpv 外挂编号误判。VLC 第二字幕回退文字，不要求 ASS 特效一致。
- PiP 与应用截图包含原生 ASS，且没有重复纯文字；恢复主窗口与播放状态正常。tvOS 抽样原第二文字/图片路径，VLC 普通文字及生成/翻译链路保持原显示。

本清单用于“没有自动化测试”的前提下，给 AI / 人工开发提供一套高性价比的最小回归兜底。

## 2. 本地与远程播放

- macOS Jellyfin 轮播：抽样只有 SeriesId、只有 ParentThumb、只有自身 Thumb 以及自带海报/背景的条目，确认背景与缩略图可加载、已有图片优先，三端条目数量与顺序保持一致。

- iOS 媒体库一致性改动时（操作前须按 3.8 获批）：Jellyfin/Emby/Plex 分别点击首页轮播背景/标题和播放按钮，前者进入详情、后者播放/续播；Series/Season/Episode 保留所属剧集定位。普通 iPhone、Duo、iPad/窄分屏检查详情左右安全区、播放按钮（窄 iPhone 填可用宽度，iPad/宽布局最多 360）和全操作按钮开启后的换行；返回/首页/退出、下载/收藏及原播放入口不变。Plex 分类顶部直接显示筛选，通过视图菜单“浏览”分区切换当前库/合集，标题和选中标记一致，合集不误显示影片总数；类型/年份组合筛选、搜索、排序、分页、快速切换模式和详情返回不串旧结果，筛选值来自服务端；服务器无筛选接口时仍可浏览。查看全部保持原位置。

- iOS 媒体库返回/首页工具栏（操作 App 前按 3.8 获批）：Jellyfin/Emby/Plex 从分类 → 影片详情 → 演员作品 → 影片详情，核对返回和首页相邻且间距一致、图标同样式；返回逐级回原页并保留滚动现场，首页回当前全屏服务器库且不关闭服务器。另抽样 Plex 首页搜索与合集详情的两个按钮、边缘返回手势，以及历史/收藏进入详情；iOS 15 与 iOS 26、Duo 侧栏分别抽样，原生搜索展开/关闭、排序和下载入口保持。

- iPhone Duo 自适应改动时（操作 Device Hub / App 前按 3.8 获批）：
  - 外屏 → 内屏 → 窄分屏 → 外屏检查轮播、文件网格及 Jellyfin/Emby/Plex 演职员页；搜索、详情返回、滚动现场与当前选中项保持，原生工具栏及侧边安全区不遮挡内容。
  - Jellyfin/Emby/Plex 首页与影片详情、VOD 首页分别检查左右内容边距：无工具栏的一侧不复制另一侧的大块安全区，分区首张卡片和详情按钮可见；「我的媒体」卡片间距在图片加载前后和内外屏切换后保持，横图/竖图均不撑宽列。分类与影片详情均按返回、首页顺序侧排；返回只退一级、房子回服务器首页、根页退出回原入口。普通 iPhone 横竖屏抽样原顺序及返回语义。
  - 窄屏 Duo 的 Jellyfin/Emby/Plex 电影与剧集详情：海报、正文和播放按钮使用扩展后的内容区，右侧按钮下方不再整列空白；Jellyfin 加载“接下来播放”后背景不偏移。演职员/相关推荐不重复向屏外扩宽，末项可滚到工具栏内侧点击；滚动至按钮附近仍能操作原生返回/首页/下载。普通 iPhone、iPad/窄分屏及宽布局保留原安全区与播放按钮宽度规则。
  - 视频播放中/暂停中切换形态，进度、主/第二字幕和缩放保留；窄窗口菜单与播放键不重叠，拖动预览或双指操作中切换不误 seek、不残留手势锁，随后仍能继续操作。
  - 普通大屏 iPhone 横屏打开竖视频且启用“跟随视频比例”时仍可回竖屏，旧系统行为保持；Duo 内屏宽高均为 regular 时保留当前姿态，不因只判断 regular 宽度误拦截普通横屏旋转。

  - 侧边空闲空间修正：Jellyfin/Emby/Plex 首页继续观看/接下来播放/收藏/最新内容、详情演职员及相关推荐、VOD 首页分区横向列表延伸到边缘，末项可滚回安全区并点击；分类/合集/演职员作品及 VOD 分类/搜索网格按列宽显示海报且仍避让侧栏，检查增减一列的边界、图片比例与返回后的滚动现场，iOS 15/26 和无侧栏布局保留原卡宽；全屏视频中部按钮和底部进度/控制按自身区域避让状态栏及相机，顶部按钮行独立测量，展开后无实际遮挡时释放侧边留白，折叠后存在遮挡仍避让；时间/电量行保持原边距。检查状态栏显隐、旋转/分屏、内外屏切换及滑块拖动期间宽度变化不误 seek；活动折叠区域保守回退，普通设备与旧系统布局不变。

- macOS 本地目录授权改动时（操作 App 前须按 3.8 获批）：重复选择需要授权的同一目录，验证真实路径与沙盒链接记录均可进入、警告刷新且重启后仍可访问；同名不同目录不受影响，取消授权保留旧状态，首页添加与子目录新建入口保持可用。对解析到同一目录的两张首页卡片分别重命名和移除，确认只操作对应授权记录，重命名不改磁盘目录，另一条记录仍可用；子目录重命名与从收藏定位到链接下的子目录保持可用。
- macOS 保留不可读的默认 Movies 父目录，仅授权其中 Videos 子目录，确认 Videos 及更深层目录可浏览，不因父目录状态误报重新授权；从真实路径或沙盒链接定位时均优先使用最近的授权记录，没有子目录授权时仍回退到已有父目录授权。
- 本地视频可进入默认全屏播放器并正常开始播放。
- 音频条目仍走 sheet/浮窗链路，不误进视频全屏链路。
- iOS 慢加载/失败提示变更时，抽样验证以下场景（操作前须按 3.8 获批）：
  - 普通加载、短暂 seek 缓冲保持原视频小胶囊 / 音频纵向指示器，不出现固定宽度大 loading 背景；横竖屏下慢加载文案仍可读。
