# 自动提交与推送 (Auto Commit & Push)

当用户触发此工作流时，请严格按照以下步骤执行：

1. **检查状态与更改**：
   - 运行 `git status` 检查当前工作区状态。如果没有任何更改，直接告知用户无需提交并终止流程。
   - 运行 `git diff` （如果已有暂存文件则运行 `git diff --cached`，或者两者都运行）来分析当前代码的具体更改内容。

2. **生成提交信息**：
   - 根据代码更改内容，自动归纳总结并生成一个专业的 Git 提交信息。
   - 建议遵循常见规范，如使用 `feat:`, `fix:`, `refactor:`, `style:`, `docs:` 等前缀。

3. **执行提交与推送**：
   - 运行 `git add .` 将更改添加到暂存区。
   - 运行 `git commit -m "<你生成的提交信息>"` 完成本地提交。
   - 运行 `git push` 将提交推送到远程仓库。

4. **回显提交消息**：
   - 任务完成后，在回复中明确向用户展示你生成的具体**提交消息 (Commit Message)**，并告知推送成功。
