# GenPlayer Terminology

## Product Tone

- English: concise, natural, app-style wording
- Simplified Chinese: direct and clear, not overly literal
- Avoid marketing-heavy wording in operational UI

## Canonical Names

Keep these names canonical:

- GenPlayer
- Jellyfin
- Emby
- Plex
- WebDAV
- SMB
- Face ID
- Touch ID

## Preferred Concepts

- `View Details` for media-library entries
- `Show in Folder` for file-oriented entries
- `Download`, `Offline`, and `Cache` must remain distinct
- `History` and `Favorites` should stay consistent with project navigation rules
