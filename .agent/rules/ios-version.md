1. 记住 iOS 版本是 15+，tvOS 版本是 16+，使用高版本语法时注意判断版本
2. 代码修改完成后使用 xcodebuild 纯构建验证并修复编译问题；纯文档改动只检查内容与差异。模拟器操作、录屏、截图或 GUI 验证须遵守 AGENTS.md 3.8 的用户审批要求。
3. 任务收尾时只将最终结果、最终验证结论与必要风险简要写入 docs/tasks/dev-log/YYYY-MM.md；同日同任务更新原条目，不记录中间操作或试验过程。daily_dev_log.md 仅为月份索引，读取范围遵守 AGENTS.md 第 7 节。
4. 执行计划等大变动更新到features功能列表中
5. ios图标设计是1024*1024，是个直角正方形图标，不要里面还有一层正方形圆角之类的，里面是图标设计元素，比如播放三角等。
6. 注意我们有多主题和多语言，因此开发和设计的时候注意保持主题和语言的支持
7. 不要把一些build的日志等不重要的数据放到当前工程目录并在使用后删除，防止提交到仓库中
8. 禁止自动执行 git commit 提交代码。完成代码修改并验证通过后，请通知用户，等待用户自行调用 `/commit` 工作流或给出明确的提交指令。
